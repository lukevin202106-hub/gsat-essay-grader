作文批改器

用自己的 Claude
改學測作文

貼上題目和學生的作文，照片也可以。它會照大考中心的評分表估分，英文逐句挑錯，國文逐句寫眉批，再照學生原本的骨架改寫兩版。英文也改學測中譯英，跟作文在同一頁。最後產生一頁網頁，可以直接傳給學生。

免費、開源。要有 Claude 的付費方案（Pro 以上），批改用的是你自己的額度。

一

Claude 網頁版或 App

最簡單，不用安裝

在 claude.ai 或 Claude App 裡上傳一個技能檔，之後在一般的對話裡貼作文就能批改。

下載技能檔
  1. 下載上面的 zip 檔。不用解壓縮。
  2. 打開 claude.ai 或 Claude App，到設定（Settings）→ 功能（Capabilities），打開程式執行與檔案建立（Code execution and file creation）。
  3. 到自訂（Customize）→ 技能（Skills），按 ＋ →建立技能→上傳技能（Upload a skill），選剛剛下載的 zip。
  4. 開一個新對話，在工具選單打開網路搜尋，貼上題目和作文，說「幫我改這篇作文」。
  5. 批完會給你一個網頁檔。下載以後，用瀏覽器打開就是批改頁。

介面的名稱會隨 Claude 改版調整，找不到時在設定裡找「技能」或「Skills」。對話選 Sonnet 就夠用，要最好的品質選 Opus。

二

Claude Code

完整版，四個角色分工

收集資料、診斷、改寫、盲審由四個 Claude 分開做，可以選三種等級，查過的資料會存下來給下一篇用。安裝程式會幫你裝好 Claude Code、Python 和作文批改器。需要 macOS 13 以上，或 Windows 10 以上。

Mac

下載 Mac 安裝檔
  1. 打開下載的 zip，雙擊裡面的安裝作文批改器。
  2. 如果出現「Apple 無法驗證」的視窗：先按完成，到系統設定 → 隱私權與安全性，拉到最下面按強制打開（或仍要打開）。舊一點的 macOS 可以在檔案上按右鍵 →打開。
  3. 照視窗裡的說明做。第一次可能要先裝 Apple 的「指令列工具」，裝好以後再雙擊一次安裝檔。

不想處理那個視窗的話，也可以打開「終端機」（應用程式 → 工具程式），貼上這一行，按 Enter：

curl -fsSL https://lukevin202106-hub.github.io/gsat-essay-grader/install/install.sh | bash

Windows

下載 Windows 安裝檔
  1. 在下載的 zip 上按右鍵 →解壓縮全部，打開解壓縮出來的資料夾。直接在 zip 裡面雙擊不會動。
  2. 雙擊 install.bat。如果出現藍色的「Windows 已保護您的電腦」，按其他資訊→仍要執行。
  3. 照視窗裡的說明做。沒有 Python 的話，它會自動裝。

也可以打開 PowerShell，貼上這一行，按 Enter：

irm https://lukevin202106-hub.github.io/gsat-essay-grader/install/install.ps1 -OutFile "$env:TEMP\gsat-install.ps1"; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\gsat-install.ps1"

裝好以後

  1. 「文件」裡會多一個作文批改資料夾。雙擊裡面的開始批改。
  2. 第一次會請你選配色、用瀏覽器登入 Claude，再問你信不信任這個資料夾，選 Yes。
  3. 貼上題目和作文，照片可以直接拖進視窗。說「用最好的」換成最好的等級，說「用測試等級」只用最便宜的模型試流程。
  4. 批完會在 site 資料夾產生網頁檔，雙擊就能看。

兩種有什麼不同

網頁版或 AppClaude Code
安裝上傳一個檔跑一次安裝程式
怎麼做同一個 Claude 從頭做到尾，最後自己審一次四個 Claude 分工，盲審的那一個沒看過前面的過程
模型對話選哪一個就用哪一個省錢、最好、測試三種等級，每一步配不同模型
資料每次對話重新查同一題查過的資料存下來，下一篇不用重查
成品對話裡給一個網頁檔存在電腦的資料夾，能發佈成 Claude 網頁

常見問題

要錢嗎？

作文批改器免費。批改是用你自己的 Claude，要有 Pro 以上的付費方案，用掉的算在你的用量額度裡，不另外收費。

學生的作文會傳到哪裡？

只會交給你自己的 Claude 批改。Claude Code 版的作文和成品都存在你電腦的「作文批改」資料夾；網頁版在你的 Claude 對話裡。作文批改器本身不會把作文送到別的地方。

分數準嗎？

是照大考中心的評分表估的，不是正式成績，實際閱卷可能差一兩分。每一項都會寫扣在哪裡，那些說明比分數有用。

英文裡的「學測精選」是什麼？

allinone App（App Store 搜尋「Allinone 讀書計畫」）整理的學測精選 3,000 字和 1,259 條片語句型。高分版會換成這些字，批改頁附上中文和例句。

怎麼更新、怎麼移除？
  • 更新：Claude Code 版再跑一次安裝程式；網頁版到「技能」刪掉舊的，再上傳新的。
  • 移除 Claude Code 版：在終端機或 PowerShell 打 claude plugin uninstall gsat-essay-grader@gsat-essay-grader，再刪掉家目錄裡的 .gsat-essay-grader 資料夾。「作文批改」資料夾裡是你的作文，要不要刪自己決定。
